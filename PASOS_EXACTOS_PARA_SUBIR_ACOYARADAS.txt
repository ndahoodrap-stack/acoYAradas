2) CREAR BASE DE DATOS EN SUPABASE
--------------------------------------------------------------------------------

a) Proyecto
   - Ir a https://supabase.com/dashboard
   - New Project -> elegir nombre, password de DB, región
   - Esperar a que cree

b) Copiar datos
   Settings -> Database
   - Connection string -> URI (Transaction mode) Puerto 6543 -> COPIAR (pooler)
   - Connection string -> URI (Session/Direct) Puerto 5432  -> COPIAR (directa) [para migrar]

   Settings -> API
   - Project URL -> https://<ref>.supabase.co
   - anon public key
   - service_role key (SECRETA, NO usar en frontend)

c) Crear bucket de Storage
   Storage -> New bucket
   - Name: public
   - Public bucket: SI (marcado)
   - Create bucket


--------------------------------------------------------------------------------
3) APLICAR MIGRACIONES DESDE TU PC
--------------------------------------------------------------------------------

Abrí terminal en "E:\Nueva carpeta (15)"

Pegá TUS credenciales (reemplazá):
   DIRECT_URL="postgresql://postgres.<ref>:<PASSWORD>@db.<ref>.supabase.co:5432/postgres?sslmode=require"

Ejecutá:
   set DB_MODE=supabase
   set DATABASE_URL=%DIRECT_URL%
   npm run db:migrate

Deberías ver algo como:
   [migrate] aplicando 001_schema.sql...
   ...
   [migrate] listo (X migraciones disponibles, motor: postgres)

NOTA: NO ejecutes "npm run db:seed" en producción. Los datos demo NO van a internet.

4) DESPLEGAR EN RENDER
--------------------------------------------------------------------------------

Opción A: Con render.yaml (recomendado)
   - Ir a https://dashboard.render.com
   - New + -> Blueprint
   - Conectar tu repo acoyaradas
   - Render leerá render.yaml y creará el servicio
   - Rellenar las variables que piden (ver abajo) y aplicar

Opción B: Manual
   New + -> Web Service -> conectar repo
   Runtime: Node
   Build Command: npm ci --include=dev && npm run build
   Start Command: node apps/api/dist/server.js
   Health Check Path: /api/health
   Plan: Starter (o Free para probar)
