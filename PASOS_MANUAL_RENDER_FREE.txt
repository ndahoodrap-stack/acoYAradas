================================================================================
PASOS MANUALES PARA RENDER FREE (SIN BLUEPRINT / SIN PAGAR)
================================================================================

Repositorio: https://github.com/ndahoodrap-stack/acoyaradas
Rama: master

NOTA: Render NO te deja usar Blueprint con Free. Hay que hacerlo manual.


--------------------------------------------------------------------------------
1) CREAR WEB SERVICE MANUAL
--------------------------------------------------------------------------------

1. Ir a https://dashboard.render.com
2. New + > Web Service
3. Build and deploy from a Git repository > Next
4. Conectar GitHub -> Seleccionar ndahoodrap-stack/acoyaradas -> Connect


--------------------------------------------------------------------------------
2) CONFIGURAR BUILD Y START
--------------------------------------------------------------------------------

Rellenar exactamente estos campos:

Campo                | Valor
-------------------- | -----------------------------------------
Name                 | acoyaradas
Region               | Oregon (o el que te aparezca)
Branch               | master
Root Directory       | (vacío)
Runtime              | Node
Build Command        | npm ci --include=dev && npm run build
Start Command        | node apps/api/dist/server.js
Instance Type        | Free

NO marcar "Auto-Deploy" distinto a lo normal. Con eso ya basta.


--------------------------------------------------------------------------------
3) VARIABLES DE ENTORNO
--------------------------------------------------------------------------------

Ir a Environment > Add Environment Variable y añadir TODAS estas.

REEMPLAZAR LOS VALORES ENTRE <> POR TUS DATOS REALES.

# Servidor
NODE_ENV=production
NODE_VERSION=20
PORT=3001
TRUST_PROXY=true
PUBLIC_BASE_URL=https://TU-NOMBRE-DE-RENDER.onrender.com
CORS_ORIGINS=https://TU-NOMBRE-DE-RENDER.onrender.com

# Base de datos (Supabase)
DB_MODE=supabase
DATABASE_URL=postgresql://postgres.<ref>:<PASSWORD>@<pooler-host>:6543/postgres?sslmode=require

# Autenticación
AUTH_MODE=local
AUTH_SECRET=TU_CLAVE_ALEATORIA_LARGA_GENERADA
ACCESS_TOKEN_TTL=7200
REFRESH_TOKEN_TTL=2592000

# Supabase
SUPABASE_URL=https://<ref>.supabase.co
SUPABASE_ANON_KEY=<anon-key>
SUPABASE_SERVICE_ROLE_KEY=<service-role-key>
SUPABASE_STORAGE_BUCKET=public

# WhatsApp
WHATSAPP_PROVIDER=links
WHATSAPP_OWNER_PHONE=549XXXXXXXXXX
WHATSAPP_AUTO_OPEN=true
WHATSAPP_AUTO_SEND=false

# Datos públicos
CONTACT_EMAIL=hola@acoyaradas.app
CONTACT_PHONE=+54 9 2284 55-5555
COVERAGE_TEXT=Cobertura exclusiva en San Carlos de Bolívar, Provincia de Buenos Aires.
HOURS_TEXT=Lunes a sábado de 9:00 a 21:00 h
UPLOADS_DIR=./uploads


GENERA TU AUTH_SECRET:
Abrí terminal/cmd en tu PC:
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

IMPORTANTE:
- DATABASE_URL = POOLER PUERTO 6543 (NO 5432). La 5433/5432 solo para migrar desde tu PC
- AUTH_SECRET = obligatoria y distinta
- SUPABASE_SERVICE_ROLE_KEY = SECRETA (solo en Render, nunca en frontend)


--------------------------------------------------------------------------------
4) HEALTH CHECK Y DESPLIEGUE
--------------------------------------------------------------------------------

Antes de crear el service, o tras crearlo:

1. Ir a Settings > Health Check (si aparece)
2. Health Check Path: /api/health
3. Poner Create Web Service

Esperar 5-10 minutos. Ver logs en Logs tab.


--------------------------------------------------------------------------------
5) PRUEBA INICIAL
--------------------------------------------------------------------------------

Cuando aparezca "Live" copiar la URL:
https://TU-NOMBRE-DE-RENDER.onrender.com

Probar:
curl https://TU-NOMBRE-DE-RENDER.onrender.com/api/health

O abrir directamente:
https://TU-NOMBRE-DE-RENDER.onrender.com/api/health

Debe devolver:
{"ok":true,"db":"postgres","env":"production","time":"..."}


--------------------------------------------------------------------------------
6) CREAR PRIMER ADMINISTRADOR
--------------------------------------------------------------------------------

1. Registrarte
   https://TU-NOMBRE-DE-RENDER.onrender.com/registro
   Crear cuenta con TU EMAIL

2. Dar rol admin en Supabase SQL Editor
   Copiar y pegar esto, cambiando el email:

   update public.profiles set role = 'admin' where email = 'TU-EMAIL@DOMINIO.COM';
   update public.local_users set role = 'admin' where email = 'TU-EMAIL@DOMINIO.COM';

   Ejecutar (Run)

3. Entrar al panel
   Cerrar sesión y volver a entrar
   Ir a https://TU-NOMBRE-DE-RENDER.onrender.com/admin

NOTAS
--------------------------------------------------------------------------------

- Plan Free: se duerme tras inactividad. Al primer acceso tras dormir tarda 30-60s en despertar.
- Es efímero: si NO usás Supabase Storage, las imágenes se pierden. Ya está configurado para usar bucket public.
- Pagos: solo efectivo/transferencia (Mercado Pago pendiente)
