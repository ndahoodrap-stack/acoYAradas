# Guía para administradores — acoYAradas!

## Acceso

- Ingresar con la cuenta de rol `admin`.
- Panel: `/admin`.

## Tareas principales

- Aprobar/suspender comercios.
- Gestionar usuarios y roles.
- Administrar pedidos y asignar repartidores.
- Configurar categorías, zonas, tarifas, planes, comisiones.
- Gestionar banners y campañas publicitarias.
- Consultar dashboard, reportes CSV y auditoría.
